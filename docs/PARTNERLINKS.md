```json

{ "id": "uneed", "coupon": { "code": "AIGEDDON20", "text": "20% discount" } }
```

oder als Zeile an Claude: `PARTNERLINK <id> <link>` bzw. `CODE <id> <CODE> <Rabatt>`.
